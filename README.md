# Hemp-Bio-DropStitch: Биоразлагаемый конопляный пневмокаркасный композит

**Статус проекта:** Общественное достояние (Public Domain / CC0 1.0).  
Технология открыта для свободного копирования, производства и применения без патентных ограничений.

---

## Суть инженерного решения

**Hemp-Bio-DropStitch** — рулонный композитный материал со стяжными нитями (Drop Stitch) для надувных силовых панелей (модули 3×3×3 м, перекрытия, понтоны) с **управляемой биодеградацией**. Материал выпускается на стандартном оборудовании для SUP-тканей и утилизируется в компосте.

---

## 1. Технологическая карта производства

* **Армирование:** конопляная пряжа (20–24 нити/см²) для геометрии плит при давлении 6–10 PSI.
* **Подготовка нити:** водорастворимая крахмальная био-шлихта с последующей промывкой водой и энзимами.
* **Биозащита:** природные антисептики (танины) против прения волокон.
* **Ламинация:** компостируемый био-термопласт **PBAT / PHBH** (*OK Compost HOME*) при 140–165 °C.
* **Сварка:** гладкая конопляная ткань с покрытием PBAT/PHBH для герметизации швов феном (180–220 °C) или ТВЧ.

---

## 2. Эксплуатационные свойства

1. **Прочность:** защита от УФ, морозостойкость, компактность в рулонах.
2. **Сборка:** термопластичность покрытия позволяет делать монолитныеарные швы.
3. **Утилизация:** полное разложение биополимера и конопли в грунте за **6–18 месяцев** без микропластика
4. **Защита** от преждевременного разложения в эксплуатации:** На открытом воздухе под солнцем и ветром полимер PBAT/PHBH и конопляная основа с танинами не подвергаются биодеградации — дождевые черви и почвенные бактерии не разрушают сухую натянутую поверхность. Процесс разложения запускается **исключительно по команде владельца** при одновременном сочетании трёх факторов: нарушении герметичности (разрезании панелей), постоянной высокой влажности и погружении в активную почвенную микрофлору (компост).
